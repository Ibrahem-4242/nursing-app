# 🩺 نيرسنج هَب (Nursing Study Hub) 🚀
### المنصة الطبية التفاعلية لملخصات وكويزات التمريض ومجسمات Three.js ثلاثية الأبعاد

تم تحويل منطق وهيكل بوت التليجرام الخاص بـ **Google Apps Script** إلى موقع ويب عصري فائق السرعة مبني بأحدث معايير **Next.js (App Router)**، **Tailwind CSS**، ومكتبة **Three.js** ثلاثية الأبعاد، مع استيفاء كافة شروط وسياسات القبول في **Google AdSense**.

---

## 🌟 أبرز مميزات المشروع:

1. **المسارات والهيكلية التفاعلية (App Router):**
   - **الرئيسية (`/`)**: اختيار السنة الدراسية بكروت أنيقة ومجسم DNA وخلايا دم تفاعلي بـ Three.js.
   - **صفحة السنة (`/year/[yearId]`)**: استعراض كافة مواد السنة المختارة مع نصائح سريرية مخصصة.
   - **صفحة المادة (`/subject/[subId]`)**: قائمة المحاضرات والكويزات المتاحة مع تمييز المجاني والمدفوع.
   - **صفحة المحاضرة (`/lecture/[lecId]`)**:
     - مجسم تشريحي ثلاثي الأبعاد تفاعلي للأعضاء (Three.js) مع تحكم 360° ونبض قلبي.
     - ملخص نصي دسم غني بالمفاهيم السريرية والمصطلحات والتدخلات التمريضية (محتوى ثري لأدسنس).
     - بطاقات فلاش كاردز ثلاثية الأبعاد (3D Flip Flashcards) قابلة للتقليب والتنقل والخلط.
     - سكشن كويز تجريبي تفاعلي فوري مع التصحيح والتعليل الطبي واللآلئ السريرية.
     - أزرار تحميل مباشرة لكافة الصيغ (PDF, PPT, Mindmap) مع ملاحظات الإدارة.

2. **التوافق التام مع Google AdSense:**
   - مكون إعلاني ذكي متجاوب `AdSenseBanner` يمنع الـ CLS ويدعم العرض التجريبي في التطوير.
   - توزيع استراتيجي للإعلانات: أعلى المحتوى، مدمج بين الفقرات، وقبل سكشن التحميل.
   - صفحات إلزامية كاملة جاهزة: `/privacy-policy`، `/terms`، `/about`، `/contact`.
   - إعداد الـ `RootLayout` لدعم سكريبت AdSense التلقائي عبر متغيرات البيئة.

3. **مجسمات Three.js ثلاثية الأبعاد:**
   - مجسم السلسلة الوراثية والنبض الخلوي في الهيرو (`MedicalHero3D`).
   - فاحص الأعضاء التشريحية التفاعلي مع نمط Wireframe ونبض عضلي (`MedicalOrganViewer`).

4. **طبقة البيانات والتكامل السحابي:**
   - ملف `mock-data.ts` يعكس بدقة شيتات البوت (`Files`, `Users`, `Purchases`).
   - خدمة `DataService` مع مسار API جاهز (`/api/sync`) للربط مع Google Sheets وApps Script Web App.

## ⚙️ ربط Google AdSense
في ملف `.env.local`:
```env
NEXT_PUBLIC_ADSENSE_CLIENT_ID=ca-pub-XXXXXXXXXXXXXXXX
```
استبدل المعرف برقم الناشر الخاص بك من Google AdSense وسيتم تشغيل الإعلانات تلقائياً على كامل الموقع.
